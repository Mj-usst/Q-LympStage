# Q-LympStage

Code accompanying the manuscript:

**Quantitative CE-MR Lymphangiography for Staging Lower-Extremity Lymphedema: Multicenter and Prospective Evaluation**

Q-LympStage is a quantitative CE-MR lymphangiography (CE-MRL) workflow for three-class International Society of Lymphology (ISL) staging of lower-extremity lymphedema using predefined morphologic measurements and radiomic features.

## Analysis workflow

1. **Image preprocessing**  
   Resample CE-MRL images and VOI masks to isotropic 1 × 1 × 1 mm³ geometry. Continuous MR images use B-spline interpolation and segmentation masks use nearest-neighbor interpolation.

2. **Radiomic feature extraction**  
   Extract 1116 non-shape radiomic features from the subcutaneous-tissue VOI using PyRadiomics. The feature set consists of 93 first-order/texture features from each of 12 image types: Original, eight Wavelet decompositions, and three Laplacian-of-Gaussian images (σ = 1.0, 2.0, and 3.0 mm).

3. **Morphologic feature extraction**  
   Calculate nine prespecified morphologic measurements from bone, muscle, and subcutaneous-tissue VOIs, including middle-third volumes, maximum cross-sectional-area measurements, and tissue area/volume ratios. The upper-to-lower subcutaneous-tissue area ratio uses the superior and inferior boundary slices of the osseous middle third.

4. **Model development and testing**  
   Use Centers 1-3 jointly for model development/internal testing and Center 4 only for independent external testing. Stage 0 is mapped to stage I before any cohort filtering. Perform patient-level data partitioning and five-fold stratified group cross-validation with `random_state=255` for both split steps. The nine morphology and 1116 radiomics candidate columns are validated using only the training+validation development partition; internal, external, and prospective test values cannot influence candidate-column eligibility. For both binary and three-class analyses, retain the top 50 ANOVA-ranked radiomic features before correlation filtering and use L1 logistic regression with `solver="saga"`, `C=0.05`, `max_iter=20000`, and `random_state=255` for sparse selection. If LASSO retains no radiomic feature, the fixed fallback retains the first `min(10, n_features)` features after Pearson filtering. PyRadiomics `diagnostics_*` columns and shape features are excluded. Candidate feature configurations are radiomics only, morphology only, and combined radiomics+morphology. Candidate classifiers include logistic regression, random forest, support vector machine, and XGBoost when installed. Model selection is based on mean cross-validation AUC, followed by accuracy and PPV.

5. **Locked-model evaluation**  
   Evaluate a locked binary or three-class model in internal holdout, independent external, and prospective temporal test cohorts without additional feature selection or hyperparameter tuning. Stage 0 is mapped to stage I before evaluation. `performance_metrics.csv` includes patient-cluster bootstrap 95% confidence intervals for discrimination/classification metrics, Brier score, calibration intercept, and calibration slope. Three-class calibration is reported one-vs-rest for stages I, II, and III. Supplying `--comparison-model` additionally produces paired bootstrap differences in accuracy and AUC.

6. **Secondary analyses**  
   Run calibration/Brier-score/ROC/decision-curve analyses, prespecified subgroup analyses, segmentation/feature reproducibility analysis, and SHAP interpretation. Stage 0 is consistently mapped to stage I. Subgroup analysis defaults to the independent external test center (`中心4`): etiology is evaluated as primary versus secondary, and stage concordance is evaluated only among bilateral patients as concordant versus discordant. Missing model features are median-imputed by the locked pipeline and subgroup bootstrap sampling uses seed 255. The reader study reported in the manuscript is not regenerated by a separate public script in this release.

## Radiomics configuration

`radiomics_config.yaml` mirrors the radiomic settings described in the supplementary methods:

- PyRadiomics 3.0.1
- SimpleITK 2.5.2
- fixed bin width = 25
- z-score normalization (`normalize=True`, `normalizeScale=1`)
- no outlier clipping
- 3D extraction (`force2D=False`)
- foreground label = 1
- geometry tolerance = 1e-3
- Original + Wavelet + LoG image types
- LoG σ = 1.0, 2.0, and 3.0 mm
- shape features excluded because morphology is analyzed separately

Because images are resampled before PyRadiomics processing, `resampledPixelSpacing` is set to `null` in the configuration to avoid repeat resampling.

## Important implementation notes

### Patient-level separation

All development/test partitioning and cross-validation must preserve the patient as the grouping unit so that bilateral limbs from the same patient cannot enter different folds or holdout partitions. The public workflow intentionally does **not** fall back to row-level stratified cross-validation when grouped splitting fails.

### Bootstrap confidence intervals

For model-level analyses in which bilateral limbs can occur, confidence intervals should be obtained by resampling **patients as clusters**, not individual limbs independently. The relevant scripts therefore require or use a patient identifier for clustered resampling.

### Prospective temporal cohort

The prospective temporal cohort is evaluated only after model locking. It must not be used for feature selection, candidate-model selection, threshold tuning, or hyperparameter selection.

### Reproducibility ICC

`07_reproducibility_analysis.py` uses ICC(2,1): a two-way random-effects, absolute-agreement, single-measurement model. This treats the two repeated segmentations/measurements as representative of a wider reproducibility process and penalizes systematic disagreement.

### Morphologic upper-to-lower ratio

`underskin_middle1of3_top_bottom_area_ratio` is the subcutaneous-tissue cross-sectional area at the superior boundary slice divided by that at the inferior boundary slice of the osseous middle third. Image orientation metadata are used to identify superior and inferior.

### SHAP figure outputs

`08_shap_analysis.py` generates the complete Figure 6 analysis set: global mean absolute SHAP importance, distributions of `wavelet-LLH_ngtdm_Coarseness` and `underskin_bone_middle1of3_volume_ratio` across stages, and one-vs-rest SHAP beeswarm summaries for stages I, II, and III.

## Data availability and privacy

This repository is intended to contain **analysis code, configuration, and non-identifiable documentation only**.

Do **not** commit clinical DICOM images, NIfTI images, segmentation masks, spreadsheets containing patient identifiers, medical record numbers, dates, or other protected health information unless sharing is specifically authorized by the applicable ethics approval, institutional policy, and data-use agreements.

The `.gitignore` therefore excludes common clinical-imaging and spreadsheet formats by default.

For public reproducibility examples, use synthetic or fully de-identified data whose release has been explicitly authorized.
